Onboarding Triage Agent is a Python project built on the Claude API that triages SaaS security onboarding issues such as SSO failures, connector authentication errors, permission problems, and data sync delays. It classifies each issue, retrieves guidance from a small library of public vendor documentation, and drafts a customer-ready response with a confidence score. Low-confidence cases are escalated to a human. It is evaluated against a set of synthetic test cases, with accuracy and escalation rate reported. No real customer data is used.
